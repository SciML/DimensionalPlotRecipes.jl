# DimensionalPlotRecipes.jl

Recipes for visualizing high-dimensional numbers and reductions with
[Plots.jl](https://github.com/JuliaPlots/Plots.jl), for data visualization in
scientific machine learning (SciML).

## Installation

To install DimensionalPlotRecipes.jl, use the Julia package manager:

```julia
using Pkg
Pkg.add("DimensionalPlotRecipes")
```

## API

```@autodocs
Modules = [DimensionalPlotRecipes]
```
